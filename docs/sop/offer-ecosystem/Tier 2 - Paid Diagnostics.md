# Tier 2 — Paid Diagnostics

> [!purpose] Purpose
> Paid discovery, programmatic analysis, and strategic prescription. This is where you avoid selling "AI tools" too early — the diagnostic tells the client what system they actually need.

> [!important] Positioning
> A diagnostic is **not** "a consultation." It is a **programmatic business scan** that produces a **decision-ready report**.

## Core paid diagnostics

| Paid Diagnostic | Purpose | Next Step |
| --- | --- | --- |
| **Revenue Leak Diagnostic** | Finds missed revenue in calls, follow-up, pipeline, attribution | [[ResponseOS]] or workshop |
| **AI Readiness Diagnostic** | Tests whether the business is ready for AI implementation | Agent OS solution |
| **Founder Intelligence Diagnostic** | Maps operations, workflows, decision bottlenecks, data gaps | Blueprint or Agent OS |
| **Content Engine Diagnostic** | Audits content, podcast, authority, repurposing | [[PodcastOS]] |
| **Business Memory Diagnostic** | Audits SOPs, docs, decisions, CRM notes, knowledge loss | [[ReKonr OS]] |

## SOP rules
- Every diagnostic must output a **decision-ready report** with a single recommended next system.
- Never recommend more than one Agent OS at the close — prescription, not a menu.
- Price reflects the analysis + report, not "time on a call."
