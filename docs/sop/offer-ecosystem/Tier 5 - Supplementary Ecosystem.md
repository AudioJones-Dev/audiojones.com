# Tier 5 — Supplementary Ecosystem

> [!warning] These support the ecosystem but must **not** confuse the main buyer path. Community is not the main offer for high-ticket clients.

## Community

> [!purpose] Purpose
> Education, retention, belonging, content distribution, audience warming.

| Offer | Role |
| --- | --- |
| **Eightee20 Society (Free Community)** | Audience-to-community bridge |
| **Signal Room** | Paid entry community |
| **Operator Lab** | Builder implementation community |
| **Founder Systems Circle** | Premium advisory / community layer |
| **Build Sprints** | Cohort implementation products |

How community supports the funnel:
```txt
Community → Workshops
Community → Diagnostics
Community → Agent OS
```
