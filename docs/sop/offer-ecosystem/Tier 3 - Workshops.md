# Tier 3 — Workshops

> [!purpose] Purpose
> Convert people who need education, strategy, or guided implementation before they are ready for a full Agent OS solution.

## Best for
- People who need education before buying
- Lower-budget buyers
- Group / cohort implementation
- Community members
- Founders/operators who need clarity before a diagnostic
- Leads who are not ready for a full install

## Workshop offers

| Workshop | Best For |
| --- | --- |
| **Revenue Leak Workshop** | Founders who want to understand missed revenue |
| **AI Readiness Workshop** | Businesses considering AI but lacking clarity |
| **Founder Intelligence Workshop** | Owners who need operating clarity |
| **ResponseOS Workshop** | Leads with missed calls / follow-up problems |
| **ReKonr OS Workshop** | Teams with scattered knowledge and weak documentation |
| **PodcastOS Workshop** | Creators / founders needing a content system |
| **Offer Architecture Workshop** | Consultants / builders turning expertise into offers |

## Position in the path
Workshops can sit **after free lead gen** or **after a paid diagnostic**. Both are valid.

```txt
Free Lead Gen → Workshop → Paid Diagnostic
Free Lead Gen → Paid Diagnostic → Workshop → Agent OS
```

## SOP rules
- Every workshop ends with a **clearer operating decision** (a system map, readiness score, or next system) — not just content.
- A workshop is a qualification + warming surface; always name the next step toward a diagnostic or [[Tier 4 - Agent OS Solutions]].
