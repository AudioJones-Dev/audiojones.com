## 1. Rules

These are **seed concepts, not approved target keywords**.

Do not infer search demand from inclusion here. Each seed must eventually be classified using:

- demand/volume,
- SERP intent,
- commercial intent,
- ICP fit,
- geographic intent,
- Audio Jones right-to-win,
- existing URL fit,
- competition,
- evidence confidence,
- conversion potential.

The register intentionally includes competing language so the evidence can reject weak terminology.

- SERP type,

- source timestamp.

Do not merge provider metrics as if they use identical methodology.

## 14. Promotion Gate

A seed is promoted into `QUERY_OPPORTUNITY_REGISTER.md` only when there is enough evidence to classify:

`query → ICP → pain/outcome → intent → Audio offer → current/new URL → commercial value → evidence confidence`

Until then it remains a research input, not a site recommendation.
