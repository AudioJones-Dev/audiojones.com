# Content Cluster Opportunity Map

Generated: 2026-06-29  
Evidence: Firecrawl summaries and local Audio Jones strategy docs.

## Strategic Read

Audio Jones should not rebuild itself as a podcast-production or generic AI SEO site. The opportunity is to use competitor structures as proof of search demand, then route that demand into the Founder Intelligence category.

The best content path is:

1. Answer the known questions.
2. Reframe them through founder-led service business operations.
3. Route each page to the diagnostic or the relevant system offer.

## Internal Linking Model

Each cluster page should link to:

- One canonical framework page.
- One diagnostic or pricing page.
- One proof/case-study page.
- One next educational page.

Avoid generic "read more" linking. Use descriptive anchors tied to the user's problem.

## Claim-Safety Notes

- Do not claim market rankings without verified search data.
- Do not use competitor statistics unless independently verified from primary sources.
- If a page cites a number, record source URL and access date.
- Keep modeled estimates clearly labeled as modeled estimates.
