# AGENTS.md - Skills DOX

## Purpose

- Own repo-local AI skill documents and reusable task instructions.

## Ownership

- Applies to `skills/`.
- Global Codex skills outside this repo are not owned here.

## Local Contracts

- Skill instructions must not weaken root AGENTS.md, DOX, security, Firebase,
  or approval-gate rules.
- Skills should point agents to canonical repo docs instead of embedding stale
  duplicates.

## Work Guidance

- Keep skills narrow, operational, and easy to apply.
- Update a skill when repeated workflow behavior becomes durable for this repo.

## Verification

- Docs-only skill edits usually need no code gate.
- If a skill references commands, verify the command names still exist.

## Child DOX Index

- No child AGENTS.md files are currently defined under `skills/`.
